# 🚌 Bus Cignal (v1.0 확정)

> **CCC 전국 여름 수련회 타지구 차량 매칭·소통 통합 서비스**
> 운영 주체: CCC IT 사역부 · 목표: 2026 여름 수련회 (07~08월)
> **v1.0 확정 — 2026-05-26 (팀 회의 후)**

---

## 한 줄 소개

> 카톡 오픈채팅으로 처리하던 **타지구 차량 자리 나눔**을 시스템으로 — 공정하게, 투명하게, 편리하게.

---

## 🤔 왜 이 시스템이 필요한가요?

### 지금까지의 방식

1. 각 지구 차량 담당 간사가 본인 지구 배차 완료
2. 남는 자리를 전국 차량 간사 톡방에 공지
3. 다른 지구 간사들이 채팅으로 선착순 손들기 ("저희 3명 가능할까요?")
4. 매칭 후 1:1 톡으로 송금 정보 교환
5. 운행 당일 학생·간사 픽업 안내도 1:1 톡

### 이때 발생하는 어려움

| 문제 | 영향 |
|---|---|
| 채팅 순서가 곧 선착순 | 누가 먼저였는지 분쟁 발생 |
| 메시지 묻힘 (활동량 많은 톡방) | 자리 놓침 |
| 송금 확인이 1:1로 분산 | 중복 송금·누락 |
| 학생 명단이 자투리 톡으로 확정 | 명단 누락, 당일 미탑승 사고 |
| 정산이 사람 머릿속에만 | 회계 불투명, 사후 추적 어려움 |
| 본인 지구 차 떠난 후 학생이 타지구 차 탈 때 | 본인 지구 간사 관리 불가 → 학생이 직접 공급 지구 간사와 소통 |

---

## ✨ Bus Cignal이 해결하는 것

| 기능 | 효과 |
|---|---|
| **선착순 자동 큐 (FIFO)** | 신청 시각 기준. 누가 먼저인지 시스템이 명확히 판정 |
| **공급 지구 1번째만 승인** | 친한 지구 선별 승인 차단, 공정성 강제 |
| **부분 매칭** | 자리 부족 시 요청 지구가 어떤 학생 먼저 매칭할지 직접 선택 |
| **24시간 송금 데드라인** | 자리 잡고 송금 안 하면 자동 만료, 다음 대기에 기회 |
| **예약번호 발급** | 학생이 카톡으로 받은 번호로 본인 매칭 조회 (별도 가입 X) |
| **Trip 채팅** | 운행 차량별 그룹 채팅, 사전 질문·당일 안내 모두 |
| **지구별 정산 ledger** | 받을 돈·보낼 돈 자동 집계, 한눈에 |
| **출발지 안전 장치** | 출발 12시간 전 미입력 시 화면 잠금·마스터 개입 |

## 👥 누가, 어떻게 쓰나요?

### 🧑‍✈️ 공급 지구 간사 (자리 내놓는 쪽)

1. Google 계정으로 로그인
2. 본인 지구 차량 등록 (방향·출발지·시간·정원·요금·출발지 주소)
3. 본인 지구 배차 후 남는 자리 공개 (토글 ON)
4. 다른 지구 신청이 큐에 쌓이면 **1번부터 차례로** 승인·거절
5. 잔여 자리보다 많이 신청? → 부분 매칭 진행 (B에게 학생 선택 권한 이양)
6. 요청 지구가 송금 완료 누르면 → 통장 확인 → "입금 확인" 클릭
7. 시스템이 예약번호 발급 → 요청 지구가 학생에게 카톡 공유

### 🧑‍✈️ 수요 지구 간사 (자리 받는 쪽)

1. 다른 지구 운행 검색 (출발지·도착지·날짜)
2. 매칭 가능한 차량 카드 보기 (잔여·가격·출발지·대기 큐 길이)
3. **학생 명단 입력 + 본인 동의 confirm** → 신청
4. 매칭 확정 알림 → **24시간 안에 송금 + "송금 완료" 클릭**
5. 공급 지구가 "입금 확인"하면 예약번호 받음
6. 학생에게 **예약번호 + 링크 카톡 공유** (시스템이 안내 문구 자동 생성)

### 🧑‍🎓 학생

1. 본인 지구 간사로부터 카톡으로 예약번호 + 링크 받음
2. 링크 클릭 → 본인 이름 확인 (별도 가입 X)
3. 내 매칭 화면에서:
   - 어느 차 · 언제 · 어디서 · 얼마
   - 출발지 지도 (카카오맵 임베드)
   - 담당 간사 연락처
4. **Trip 채팅 입장** → 사전 질문·당일 소통

### 👤 마스터 (CCC IT 사역부)

- 전국 매칭·정산 모니터링
- 출발지 미지정 위험 Trip 목록 → 직접 카톡·전화 개입
- 거절 패턴 모니터링
- 신청 마감일·점검 모드 settings

## 🔧 우리가 신경 쓴 디테일

### 공정성
- 신청 시각 기반 FIFO. 채팅 순서 같은 모호함 없음
- 친한 지구 선별 승인 차단 (큐 1번째만 [승인] 활성)
- 거절 시 사유 필수 입력 + 마스터에게 알림 (패턴 모니터링)

### 안정적 채팅
- Firebase Firestore 사용 — Google 글로벌 다중리전, 오프라인 캐시·자동 재연결
- 셀룰러·WiFi 끊겨도 메시지 손실 없음
- 운행 당일 "유일한 소통수단"이 될 수 있다는 가정으로 인프라 선택

### 출발지 안전 장치
- 출발 시각 12시간 전까지 출발지 미입력 시 → 공급 지구 간사 화면이 잠금 (입력 전엔 다른 작업 불가)
- 마스터 화면에 위험 Trip 모아보기 → 직접 카톡·전화 개입

### 송금 책임 분리
- 매칭 → 송금 완료 클릭: **24시간** (자동 만료, 요청 지구 책임)
- 송금 완료 → 입금 확인: 시간 제한 없음 (공급 지구 페이스)
- 실제 미입금 시 공급 지구가 매칭 취소 권한

### 개인정보 보호
- 최소 수집 (이름·전화·소속)
- 학생 본인 동의는 신청 지구 간사가 책임지고 수령 (시스템 confirm 체크)
- 수련회 종료 + 90일 후 자동 익명화
- 마스터 인증 = Google OAuth + 추가 비밀번호 (2단계)
- 한국 PIPA 준수

### 학생 진입 마찰 최소화
- 별도 가입 X — 예약번호 + 본인 이름만 입력
- 카톡 링크로 바로 진입
- 세션 30일 유지

## 🙋 자주 묻는 질문

**Q1. 차량 간사가 아니어도 쓸 수 있나요?**
직접 시스템에 로그인하는 사용자는 각 지구 차량 담당 간사입니다. 학생은 본인 지구 간사로부터 받은 예약번호로 본인 매칭만 조회 가능합니다.

**Q2. 송금은 시스템에서 처리하나요?**
송금 자체는 기존처럼 지구 간 직접 계좌이체. 시스템은 송금 완료 보고·입금 확인을 추적하고 정산 ledger를 자동 생성합니다.

**Q3. 24시간 안에 송금을 못 하면요?**
매칭이 자동 만료되고 자리가 다시 풀립니다. 큐 다음 지구가 1번이 되어 공급 지구의 승인을 기다립니다.

**Q4. 매칭 후 취소는 가능한가요?**
요청 지구가 송금 완료 보고를 했는데 실제 입금이 없으면 공급 지구가 매칭 취소 권한을 가집니다. 정상 매칭 취소는 신중히 진행해야 합니다.

**Q5. 학생 정보는 누가 보나요?**
매칭 양측 지구 차량 간사만 봅니다. 다른 지구나 외부에는 공개되지 않습니다.

**Q6. 카카오톡 알림톡으로 안내 자동 발송하나요?**
V1.0은 인앱·이메일 알림만 사용합니다. 사업자 등록이 필요한 카카오 알림톡은 V2에서 검토합니다.

**Q7. 학생이 시스템 알림을 받나요?**
학생은 매칭이 paid 처리될 때 신청 지구 간사로부터 카톡으로 예약번호와 링크를 받습니다. 시스템이 직접 학생에게 알림을 보내지 않습니다.

**Q8. 매칭된 차량의 출발 장소가 변경되면 어떻게 되나요?**
변경 시 매칭된 학생 전원·신청 지구 간사 전원에게 자동 알림 발송됩니다. Trip 채팅에도 시스템 메시지로 기록됩니다.

**Q9. 카톡 오픈채팅은 계속 쓰나요?**
간사 간 일반 대화는 카톡 오픈채팅 그대로 유지 권장. 시스템은 매칭·정산·학생 안내·운행 당일 채팅에 집중합니다.

**Q10. 데이터는 얼마나 보관되나요?**
수련회 종료 후 90일 동안 보관되며, 이후 개인 식별 정보는 자동으로 익명화됩니다. 정산 데이터는 회계 의무로 5년 보관됩니다 (개인 식별 부분은 마스킹).
