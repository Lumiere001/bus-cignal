# 🚌 Bus Cignal

> **CCC 전국 여름 수련회 타지구 차량 매칭·소통 통합 서비스**
> 운영 주체: CCC IT 사역부 · 목표: 2026 여름 수련회 (07~08월)
> **v1.0 Confirmed Final — 2026-05-27**

---

## 한 줄 소개

> 카톡 오픈채팅으로 처리하던 **타지구 차량 자리 나눔**을 시스템으로 — 공정하게, 투명하게, 편리하게.

---

## 🤔 왜 이 시스템이 필요한가요?

### 지금까지의 방식
1. 각 지구 차량 담당 간사가 본인 지구 배차 완료
2. 남는 자리를 전국 차량 간사 톡방에 공지
3. 다른 지구 간사들이 채팅으로 선착순 손들기
4. 매칭 후 1:1 톡으로 송금 정보 교환
5. 운행 당일 학생·간사 픽업 안내도 1:1 톡

### 이때 발생하는 어려움

| 문제 | 영향 |
|---|---|
| 채팅 순서가 곧 선착순 | 누가 먼저였는지 분쟁 |
| 메시지 묻힘 | 자리 놓침 |
| 송금 확인 1:1 분산 | 중복·누락 |
| 명단 자투리 톡 확정 | 미탑승 사고 |
| 정산이 사람 머릿속에만 | 회계 불투명 |
| 본인 지구 차 떠난 후 학생이 타지구 차 탈 때 | 본인 지구 간사 관리 불가 |

---

## ✨ Bus Cignal이 해결하는 것

| 기능 | 효과 |
|---|---|
| **선착순 자동 큐 (FIFO)** | 신청 시각 기준, 시스템이 명확히 판정 |
| **공급 지구 1번째만 승인** | 친한 지구 선별 차단, 공정성 강제 |
| **우선순위 기반 자동 부분 매칭** | 자리 부족 시 간사가 등록한 우선순위대로 자동 매칭 (대기 시간 없음) |
| **24시간 송금 데드라인** | 자리 잡고 송금 안 하면 자동 만료 |
| **매칭 후 공급 측 취소 불가** | 매칭된 학생은 안심 (학생 자의 취소만 가능) |
| **학생 자의 취소** | 학생 본인이 직접 취소 가능, 양쪽 간사에 자동 알림 |
| **재신청 추천 알림** | 자리 풀리면 거절·만료된 신청 지구에 알림 |
| **예약번호 발급** | `BUS-XXXX` 형식, 학생이 카톡으로 받은 번호로 본인 매칭 조회 (별도 가입 X) |
| **Trip 채팅** | 운행 차량별 그룹 채팅, 사전 질문·당일 안내 |
| **PWA 푸시 알림** | 핸드폰 홈 화면 추가 시 출발 안내·변경 알림 |
| **지구별 정산 ledger** | 받을 돈·보낼 돈 자동 집계 |
| **간사 가입 시 출발/도착지 등록** | 운행 등록할 때 자유 입력 없이 선택만 → 미지정 사고 0 |

## 👥 누가, 어떻게 쓰나요?

### 🧑‍✈️ 공급 지구 간사 (자리 내놓는 쪽)

1. Google 계정으로 가입 → 본인 지구 선택 → **상행·하행 출발지·도착지 N개 등록** → 마스터 승인 대기
2. 승인 후 본인 지구 차량 등록 (등록한 출발지·도착지 중 선택, 자유 입력 X)
3. 본인 지구 배차 후 남는 자리 공개 (토글 ON)
4. 다른 지구 신청이 큐에 쌓이면 **1번부터 차례로** 승인·거절
5. 승인 전 안내문구: "이후 공급 지구 자의 취소가 불가능합니다. 신중히."
6. 잔여 자리보다 많이 신청? → **우선순위로 자동 부분 매칭** (간사 추가 작업 X)
7. 요청 지구 송금 완료 알림 → 통장 확인 → "입금 확인" 클릭
8. 시스템이 예약번호 발급 → 요청 지구가 학생에게 카톡 공유

### 🧑‍✈️ 수요 지구 간사 (자리 받는 쪽)

1. 다른 지구 운행 검색 (출발지·도착지·날짜)
2. 매칭 가능한 차량 카드 보기 (잔여·가격·출발지·대기 큐 길이)
3. **학생 명단 입력 + 각 학생 우선순위 부여** (잔여 자리 부족 시 우선순위 순으로 매칭)
4. 본인 동의 confirm → 신청
5. 매칭 확정 알림 → **24시간 안에 송금 + "송금 완료" 클릭**
6. 공급 지구가 "입금 확인"하면 예약번호 받음
7. 학생에게 **예약번호 + 링크 카톡 공유** (시스템이 안내 문구 자동 생성)

### 🧑‍🎓 학생

1. 본인 지구 간사로부터 카톡으로 예약번호 + 링크
2. 링크 클릭 → **본인 이름 + 전화 끝 4자리** 입력 → 진입
3. 내 매칭 화면에서:
   - 어느 차 · 언제 · 어디서 · 얼마
   - 출발지 지도 (카카오맵 임베드)
   - 담당 간사 연락처
4. **Trip 채팅 입장** → 사전 질문·당일 소통
5. (선택) 홈 화면 추가 → 푸시 알림 받기
6. **필요 시 자의적 취소** — "환불은 각 지구로 문의해주세요" 안내

### 👤 마스터 (CCC IT 사역부)

- 전국 매칭·정산 모니터링
- 간사 가입 승인·권한 관리
- 거절 발생 단순 알림 (V2에서 패턴 분석)
- 신청 마감일·점검 모드 settings
- 90일 후 자동 익명화 D-day 모니터링

## 🔧 우리가 신경 쓴 디테일

### 공정성
- 신청 시각 기반 FIFO. 채팅 순서 같은 모호함 없음
- 큐 1번째만 [승인] 활성 → 친한 지구 선별 차단
- **우선순위 자동 매칭** = 간사가 학생 등록 시 미리 부여한 순서대로

### 안정성
- 매칭 후 공급 측 자의 취소 = **불가능** (학생 안심)
- 학생 자의 취소만 가능 + 양쪽 지구에 자동 알림
- 24h 송금 데드라인 자동

### 안정적 채팅
- Firebase Firestore (Google 글로벌 다중리전, 오프라인 캐시·자동 재연결)
- 셀룰러·WiFi 끊겨도 메시지 손실 없음

### 출발지 안전 장치 (가입 시 등록으로 해결)
- 간사 가입 시 출발지·도착지 N개 미리 등록
- Trip 등록할 땐 그 중 선택만 (자유 입력 X)
- 운행 임박해서 출발지 미입력 사고 = **원천 차단**

### 핸드폰 알림 (PWA + FCM)
- 홈 화면 추가 시 푸시 알림 받음 (Android 모두, iOS 16.4+)
- 첫 매칭 paid 시점에 "푸시 받으시겠어요?" 자연스럽게 권유
- 미사용 학생도 인앱 알림으로 충분

### 학생 진입 마찰 최소화
- 별도 가입 X — 예약번호 + 본인 이름 + 전화 끝 4자리
- 카톡 링크로 바로 진입 (홈 화면 추가는 선택)
- 세션 30일 유지

### 개인정보 보호
- 최소 수집 (이름·전화·소속)
- 학생 본인 동의는 신청 지구 간사가 책임지고 수령 (시스템 confirm 체크)
- 수련회 종료 + **90일 후 매일 새벽 자동 익명화**
- 마스터 = 비밀번호 only 인증 (외부 OAuth 없음)
- 한국 PIPA 준수

## 🙋 자주 묻는 질문

**Q1. 차량 간사가 아니어도 쓸 수 있나요?**
간사만 로그인. 학생은 카톡 받은 예약번호로 본인 매칭만 조회.

**Q2. 송금은 시스템에서 처리하나요?**
송금 자체는 기존처럼 지구 간 직접 계좌이체. 시스템은 송금 완료·입금 확인을 추적하고 정산 ledger 자동 생성.

**Q3. 24시간 안에 송금 못 하면요?**
매칭 자동 만료, 자리 다시 풀림. 큐 다음 지구로 진행. 거절·만료된 신청 지구에는 "자리 났어요" 재신청 알림.

**Q4. 매칭 후 취소는 가능한가요?**
- 공급 지구 자의 취소 = **불가능** (학생 안심 보장)
- 학생 자의 취소 = 가능 (양쪽 간사에 자동 알림)
- 송금 보고했지만 실제 입금 없는 경우 = 공급 지구 [매칭 취소] 가능

**Q5. 학생 정보는 누가 보나요?**
매칭 양측 지구 차량 간사만. 외부에는 비공개.

**Q6. 핸드폰 알림은 어떻게 받나요?**
홈 화면 추가 시 PWA 푸시 알림 받음. iOS 16.4+ + Safari로 추가 / Android 거의 모두 지원.

**Q7. 환불은 어떻게 받나요?**
취소 시 시스템이 정산하지 않습니다. **각 지구 차량 간사에게 직접 문의**해 주세요.

**Q8. 출발 장소가 바뀌면 알 수 있나요?**
변경 시 매칭된 학생 전원·신청 지구 간사 전원에게 자동 알림 (인앱 + 푸시 + 채팅).

**Q9. 카카오톡 알림톡으로 받을 수 있나요?**
V1.0에서는 사업자 등록 어려워 인앱·푸시만 사용. V2에서 검토.

**Q10. 데이터는 얼마나 보관되나요?**
수련회 종료 후 90일 보관 → 매일 새벽 3시 자동 익명화. 정산 데이터는 회계 의무로 5년 보관 (개인 식별 부분 마스킹).
