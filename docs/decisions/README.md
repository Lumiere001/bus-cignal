# 결정 기록 (Decision Log)

> 의미 있는 설계·정책 판단을 기록하는 곳. 여러 문서(`CLAUDE.md`·`AGENTS.md`·`ROLES.md` 등)가 "변경 사유는 `docs/decisions/`에 기록"을 규칙으로 참조합니다.

## 언제 쓰나
- 매칭·정산·인증·RLS·스키마 등 **코어 설계 변경**
- 트레이드오프가 있는 선택 (왜 A 대신 B를 골랐는가)
- 나중에 "왜 이렇게 했지?"가 나올 만한 판단

## 파일 규칙
- 파일명: `YYYY-MM-DD-slug.md` (예: `2026-05-30-ccc-login-manual-matching.md`)
- 권장 형식:
  ```
  # 제목
  - 일자 / 결정자
  - 결정: (한 줄)
  ## 배경 / 고려한 안 / 근거 / 재검토 시점
  ```
